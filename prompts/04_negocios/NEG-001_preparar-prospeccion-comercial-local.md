# Preparar prospeccion comercial local

**Para qué sirve:** Encontrar oportunidades sin atribuir problemas no comprobados.

**Campos a personalizar:** `[SECTOR]`, `[CIUDAD]`, `[SERVICIO]`, `[PRESUPUESTO]`

## Prompt listo para copiar

Desarrolla un plan de prospección para el sector [SECTOR] en [CIUDAD] ofreciendo [SERVICIO]. Presupuesto/recursos: [PRESUPUESTO].

Define perfil de cliente ideal, señales públicas de oportunidad, propuesta de valor concreta, canales de contacto permitidos, mensaje personalizado y seguimiento respetuoso. No inventes negocios, datos de contacto, fallas web ni resultados económicos. Si hay navegación, verifica los datos empresariales y sus fechas. Entrega un plan de acciones priorizadas y un registro de prospectos vacío listo para completar.

## Comprobación del resultado

- ¿Se respondió al objetivo y se completaron las tareas autorizadas?
- ¿Se separaron hechos, inferencias y pendientes, sin inventar accesos, fuentes ni acciones?
- ¿El formato final permite usar el resultado directamente?

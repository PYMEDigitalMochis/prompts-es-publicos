# Crear propuesta profesional a cliente

**Para qué sirve:** Preparar propuesta comercial modular sin promesas infundadas.

**Campos a personalizar:** `[CLIENTE]`, `[NECESIDAD]`, `[ALCANCE]`, `[PRECIO]`

## Prompt listo para copiar

Redacta una propuesta de servicio digital para [CLIENTE]. Necesidad confirmada: [NECESIDAD]. Alcance: [ALCANCE]. Precio y condiciones autorizadas: [PRECIO].

Incluye diagnóstico basado solo en información aportada, objetivos, entregables, qué no incluye, cronograma condicionado, requisitos del cliente, precio, pagos, mantenimiento y siguiente paso. Señala claramente toda variable pendiente. Evita porcentajes de mejora, garantías de ventas o integraciones no probadas. Entrega una versión lista para presentar y un resumen breve para WhatsApp.


### Condiciones no autorizadas

**No fijes** importe, impuestos, plazo de entrega, porcentaje de anticipo, calendario de pagos, mantenimiento recurrente, mapa integrado ni servicios de terceros cuando no estén autorizados explícitamente. Usa **PENDIENTE DE ACORDAR** para cada dato no aportado. Un documento «listo para presentar» puede contener apartados pendientes; nunca conviertas una propuesta condicional en una obligación o garantía inventada.

## Comprobación del resultado

- ¿Se respondió al objetivo y se completaron las tareas autorizadas?
- ¿Se separaron hechos, inferencias y pendientes, sin inventar accesos, fuentes ni acciones?
- ¿El formato final permite usar el resultado directamente?

# Crear guion divulgativo verificable

**Para qué sirve:** Guiones claros para audio o video basados en datos trazables.

**Campos a personalizar:** `[TEMA]`, `[DURACION]`, `[AUDIENCIA]`, `[ESTILO]`

## Prompt listo para copiar

Crea un guion de divulgación sobre [TEMA] de [DURACION] para [AUDIENCIA], con estilo [ESTILO].

Organiza apertura, desarrollo progresivo, ejemplos y cierre. Especifica qué afirmaciones requieren fuentes o revisión, y evita inventar estudios o citas. Para cada sección sugiere apoyo visual u audio realizable, indicando si sería material original o si necesita licencia. Produce el texto de narración seguido de notas de producción claramente separadas. No uses música ni clips protegidos sin permiso.

## Comprobación del resultado

- ¿Se respondió al objetivo y se completaron las tareas autorizadas?
- ¿Se separaron hechos, inferencias y pendientes, sin inventar accesos, fuentes ni acciones?
- ¿El formato final permite usar el resultado directamente?

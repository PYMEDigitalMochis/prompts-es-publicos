# Crear catálogo de productos con identidad visual

**Para qué sirve:** Generar fichas verificables de productos conservando su identidad visual y archivos asociados.

**Campos a personalizar:** `[MARCA_O_PROYECTO]`, `[PRODUCTOS]`, `[PALETA_APROBADA]`, `[IMAGENES]`, `[FICHAS_TECNICAS]`

## Prompt listo para copiar

Prepara un catálogo para [MARCA_O_PROYECTO] utilizando únicamente la información aportada. Productos: [PRODUCTOS]. Paleta de colores aprobada: [PALETA_APROBADA]. Imágenes disponibles: [IMAGENES]. Especificaciones y dimensiones confirmadas: [FICHAS_TECNICAS].

Crea una ficha individual por producto con nombre, descripción útil, medidas, materiales, variantes, instrucciones de uso y precauciones solo cuando esos datos estén respaldados. Asocia cada imagen al producto correcto y documenta las versiones de cualquier archivo vectorial, si existe. Mantén el diseño coherente y señala datos, fotografías o permisos de uso aún pendientes. No inventes características, certificaciones, inventario, precios ni testimonios.

## Comprobación del resultado

- ¿El resultado responde al objetivo con datos reales y verificables?
- ¿Se distinguen acciones ejecutadas, propuestas, restricciones y pendientes?
- ¿La entrega permite continuar de forma segura y autónoma?

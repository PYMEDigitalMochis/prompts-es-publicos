# Registro de decisiones y avances

**Para qué sirve:** Producir una bitácora lista para Notion o Markdown.

**Campos a personalizar:** `[PROYECTO]`, `[SESION]`, `[EVIDENCIA]`, `[DECISIONES]`

## Prompt listo para copiar

Prepara un registro de avance para [PROYECTO]. Sesión/fecha: [SESION]. Evidencias disponibles: [EVIDENCIA]. Decisiones tomadas: [DECISIONES].

Usa encabezados: Resumen, Decisiones (qué, por qué, alcance), Cambios comprobados, Pruebas y resultados, Riesgos, Pendientes (dueño y condición de cierre), Enlaces. No inventes responsables, fechas o validaciones. Entrega Markdown copiable. Si puedes guardar en un sistema conectado y existe autorización, hazlo y devuelve la ubicación comprobada; de lo contrario, entrega el texto sin afirmar que se guardó.

## Comprobación del resultado

- ¿Se respondió al objetivo y se completaron las tareas autorizadas?
- ¿Se separaron hechos, inferencias y pendientes, sin inventar accesos, fuentes ni acciones?
- ¿El formato final permite usar el resultado directamente?
